# BusinessDirectory---Razvoj-na-Mobilni-Aplikaci
Student Project about developing a Business Directory with a supabase database using android Studio and Java 

                      Author
David Gerasimov - Goce Delcev University, Štip

                      About
A Business Directory Android application built with Java and Android Studio.
The app allows users to browse businesses by category, add new companies,
and get notified when they are near a business location.

                      Features
- 📋 Browse companies by category (Services, Fun, Industry, Education)
- 🔍 Search companies by name within each category
- ➕ Add new companies with full details
- 📍 GPS proximity notifications when within 50m of a company
- 🗺️ Open company location directly in Google Maps
- ☁️ Remote database powered by Supabase

                Technologies used
- Android Studio
- Java
- Supabase (Remote Database & REST API)
- OkHttp3 (HTTP Client)
- Glide (Image Loading)
- Google Play Services Location
